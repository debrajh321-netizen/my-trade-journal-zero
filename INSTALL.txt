MY TRADE JOURNAL — MOBILE APP INSTALL

This is the PWA version of V4. It keeps the existing app features and adds install-to-home-screen support.

IMPORTANT: A PWA must be hosted on an HTTPS website. Opening index.html directly from a ZIP will not provide the Install App option.

Android: open the HTTPS website in Chrome -> menu (⋮) -> Install app / Add to Home screen.

The current login/data system remains browser-local. PC and phone data do not sync automatically.
